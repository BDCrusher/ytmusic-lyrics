# YT-Music Lyrics 0.2.9-beta.1

Additional sources now verify automatically while the playback app is active. A valid verification token renews with one hour remaining and stays usable until its replacement arrives. The ordinary exchange preserves the challenge browser's cookies and identity. Connect sources remains available when verification needs interaction; no automatic dialog opens.

Renewal adds broker results without clearing working lyrics, resetting selection or rebuilding the native Lyrics entry. Temporary source failures have up to three attempts, respecting Retry-After. Not-found/denial/TLS/parsing failures do not loop. Bad stream events cannot block later providers; replayed results are deduplicated.

Use Full alone OR deselect every Full patch and use Lyrics-only Add-on with official Morphe1.48.0 defaults, official Third-party lyrics OFF. Enable Pre-release patches and Experimental app versions, refresh the existing source and repatch original YouTube Music9.42.52/94252240 arm64.

Four exact APK combinations, both source orders, five rejected conflicts, compiled/SDK/isolation audits, JVM tests and lint pass.114 actual-source simulated Java checks and11 verification-script checks pass. Fresh live HTTP retrieves the three earlier song examples. Unchanged renderer/native-host/navigation evidence is reused by source hash.

No live Android WebView verification or phone performance acceptance is claimed. This is active-app background work, not a persistent background service. Provider coverage is not guaranteed. The reported stutter disappearing during screen recording is retained as a clue; this release does not claim to fix it. No device/MuMu/sign/install operations.
