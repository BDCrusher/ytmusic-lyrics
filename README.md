# BDCrusher YouTube Music patches

One independent Morphe patch bundle for the original arm64-v8a YouTube Music **9.45.51** and **9.46.51**.

- **Full Collection** contains the complete personal setup.
- **Singles** contains Shaders, Volume Boost, Better Lyrics and Downloads. Select the Singles you want alongside official Morphe 2.3.0. Better Lyrics uses official Third-party lyrics and Downloads uses official Downloads as its base.

Enable **Expert mode**, **Pre-release patches** and **Experimental app versions** to choose these selections in Morphe Manager. For a side-by-side install with official Morphe, select **Clone YouTube Music** with **GmsCore support** and choose **BDCrusher side-by-side**.
