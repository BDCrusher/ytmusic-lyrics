# BDCrusher YT-Music personal patches

This repository hosts an independent Full Collection for YouTube Music, based on Morphe. The current beta targets the original Google-signed **YouTube Music 9.45.51 / 94551240**, arm64-v8a.

- [Current beta release and verification](https://github.com/BDCrusher/ytmusic-lyrics/releases/tag/v0.9.0-beta.3)
- [Previous releases for YouTube Music 9.42.52 and 9.43.51](https://github.com/BDCrusher/ytmusic-lyrics/releases/tag/v0.8.0-beta.2)
- [Add the source to Morphe Manager](https://morphe.software/add-source?github=BDCrusher%2Fytmusic-lyrics)

In Morphe Manager, enable **Pre-release patches** and **Experimental app versions** for this source. Refresh it and patch the supported original APK. See the [build instructions](BUILDING.md) and [compatibility report](Personal-Patches-9.45.51/COMPATIBILITY-9.45.51.md).
