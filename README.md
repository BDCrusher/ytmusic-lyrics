# BDCrusher YouTube Music patches

One personal Morphe patch bundle for original arm64-v8a YouTube Music **9.45.51** and **9.46.51**.

- **Full Collection** contains the complete personal setup, including Crash diagnostics.
- **Singles** contains Shaders, Volume Boost, Better Lyrics, Downloads and Diagnostics. With official Morphe 2.4.0-dev.1, list the official source first.

This prerelease improves the album-art backdrop, lyric timing at pause and resume, search completion and setup for sources that require a credential.

Enable **Expert mode**, **Pre-release patches** and **Experimental app versions** in Morphe Manager. Select official **Third-party lyrics** alongside Better Lyrics (Single) and official **Downloads** alongside Downloads (Single).
