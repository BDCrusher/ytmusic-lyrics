# BDCrusher YouTube Music patches

One personal Morphe patch bundle for original arm64-v8a YouTube Music **9.45.51** and **9.46.51**.

- **Full Collection** contains the complete personal setup, including Crash diagnostics.
- **Singles** contains Shaders, Volume Boost, Better Lyrics, Downloads and Diagnostics. With official Morphe 2.4.0-dev.1, list the official source first.

**Better Lyrics Patch** is the Android integration. **Better Lyrics Web** is the upstream browser extension. The Android version uses the personal renderer, animations, pull-out and providers in both categories. Downloads uses the personal Audio/Video pop-out where the native quality picker supplies choices.

Enable **Expert mode**, **Pre-release patches** and **Experimental app versions** in Morphe Manager. Select official **Third-party lyrics** alongside Better Lyrics (Single) and official **Downloads** alongside Downloads (Single). To export a crash report, reopen Music and use **Settings → Morphe → Crash diagnostics → Save crash report**.
