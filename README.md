# BDCrusher YouTube Music patches

One personal Morphe patch bundle for original arm64-v8a YouTube Music **9.45.51** and **9.46.51**.

- **Full Collection** contains the complete personal setup.
- **Singles** contains the same personal Shaders, Volume Boost, Better Lyrics, and Downloads features for use with official Morphe Patches 2.3.0.

Better Lyrics uses the personal renderer, animations, pull-out and provider list in both categories. Downloads uses the personal Audio/Video pop-out where the native quality picker can supply choices, with the original native confirmation, Library and export support.

Enable **Expert mode**, **Pre-release patches**, and **Experimental app versions** for individual selection. When using Singles, leave official **Third-party lyrics** and **Downloads** enabled for their respective additions. For the side-by-side package, select **Clone YouTube Music** with **GmsCore support** in Full Collection.
